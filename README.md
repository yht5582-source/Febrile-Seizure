# 小兒熱性痙攣評估與決策路徑 (Pediatric Febrile Seizure Evaluation Pathway)

這是一個專為兒科急診、兒科門診及基層醫療人員開發的單頁式 Web 應用程式 (SPA)。本工具依據美國兒科醫學會 (AAP) 最新臨床指引，協助醫師快速鑑別「單純型 (Simple)」與「複雜型 (Complex)」熱性痙攣，並自動產出是否需要安排腰椎穿刺 (LP)、腦波 (EEG) 或神經影像檢查之決策建議。

## ✨ 核心功能 (Features)

*   **紅旗警示防漏診機制 (Red Flag Screening)：** 優先篩檢病童年齡（< 6 個月或 > 5 歲）與腦膜炎/中樞神經感染徵候。若符合危險因子，系統將強制跳過常規分型，直接發出紅色警示並建議高階醫療介入。
*   **動態二分法鑑別 (Dynamic Classification)：** 透過評估「發作持續時間」、「發作型態 (全身 vs. 局部)」與「24小時內復發次數」，自動界定單純型或複雜型熱性痙攣。
*   **年齡連動處置建議 (Age-based Workup)：** 系統會針對不同年齡層（特別是 6-12 個月嬰幼兒）給予精細化的腰椎穿刺 (LP) 與腦波 (EEG) 檢查建議。
*   **醫病共享決策與衛教單列印 (Parental Education Export)：** 內建隱藏式 A4 列印排版。一鍵匯出即可將病童的臨床分型、未來的「復發率與癲癇風險數據」及「居家急救處置 SOP」印出，方便醫師直接交予家屬帶回參考。
*   **離線支援 (PWA)：** 支援安裝至手機或平板主畫面，即使在無網路的急診室地下室仍可流暢執行評估。

## 📚 參考臨床指引 (Clinical Guidelines)

*   **評估與處置基準：** 美國兒科醫學會 (AAP) 指引 - *Clinical Practice Guideline for the Neurodiagnostic Evaluation of the Child With a Simple Febrile Seizure*.
*   **預後與衛教數據：** 採用當代小兒神經學教科書與臨床共識中關於熱性痙攣復發率與發展為癲癇 (Epilepsy) 之流行病學統計。

## 🚀 部署與安裝 (Deployment)

本專案為純前端架構 (HTML/CSS/JS)，無須建置後端伺服器。

1.  **線上發布 (GitHub Pages)：**
    進入 GitHub 專案的 `Settings > Pages`，將 Branch 設為 `main` 即可自動生成對外網址。
2.  **行動裝置安裝 (PWA)：**
    使用行動裝置瀏覽器 (Safari / Chrome) 開啟網頁後，選擇 **「加入主畫面 (Add to Home Screen)」** 即可建立桌面捷徑並啟用離線功能。

## 📁 檔案結構 (File Structure)

```text
├── index.html             # 主程式（評估表單、決策引擎 /*ENGINE-START*/…/*ENGINE-END*/、衛教單列印排版）
├── tests.cjs              # 決策引擎測試：node tests.cjs
├── manifest.webmanifest   # PWA 應用程式清單
├── sw.js                  # Service Worker（離線快取）
└── icon.svg               # APP 圖示
```

## 📝 版本紀錄

- **v2.1.2 (2026-11-02)**：依 AES 2016 演算法圖修正重複給藥（僅 lorazepam IV、diazepam IV 可重複一次，midazolam 肌注與 diazepam 肛門塞劑為單次），鼻內、頰黏膜與 <13 kg 肌注劑量加註非 AES 圖中劑量；再發率改用 AFP 2019 第 2 表 14/24/32/63/75%（Berg 原表未直接讀到）。
- **v2.1.1 (2026-11-02)**：無複雜特徵時的癲癇風險改依原文：無危險因子為到 7 歲約 1%（AAP 2008）、到 25 歲約 2.4%（Annegers 1987）；有其他危險因子時只說明風險較高，不再顯示無出處的 2–5%、5–10%。
- **v2.1 (2026-11-02)**：新增教學分頁與原文校正
  - 示範病例 6 例（`#cases`，可帶入評估工具）、考題 20 題（`#quiz`，基礎與高階各 10 題）、心智圖（`#map`）。
  - 內容在 `index.html` 的 `/*TEACH-START*/…/*TEACH-END*/`，病例與部分考題由 `tests.cjs` 與引擎交叉核對。
  - 癲癇風險改依 Annegers 1987 複雜特徵數（一項 6–8%、兩項 17–22%、三項 49%）。
  - 熱性重積 LP 改為「應考慮」（AFP 2019）。
  - 居家急救藥移除 AAP 2008 全文未載明的開立條件，改為提示討論。
  - 年齡 60 個月納入典型範圍（AAP：6 through 60 個月）；midazolam IM 剛好 40 kg 為 5 mg（>40 kg 才 10 mg）。

- **v2.0 (2026-10-25)**：除錯與優化
  - LP 建議改依 AAP 2011：6–12 個月只有「疫苗未完成／不詳」才列為可考慮；「已用抗生素」適用所有年齡（舊版不論疫苗一律建議考慮、且只限 6–12 月）。
  - 複雜型不再一律安排 EEG；僅局部型／神經學異常／熱性重積建議 EEG 與 MRI。
  - 新增：發作進行中（≥ 5 分鐘）重積警示與急救 benzodiazepine 劑量（依體重）、熱性重積 (≥ 30 分) 分類、意識未恢復／Todd 麻痺／無熱發作史等紅旗、處置去向與檢驗建議。
  - 復發率改依 Berg 1997 四項危險因子（13/23/32/62/76%），癲癇風險依危險因子計算。
  - 年齡改以「月」輸入；輸入即時更新結果；Ctrl+P 直接列印也會帶入資料。
  - 補上原本缺少的 manifest、Service Worker 與圖示（舊版 manifest.json 404、無離線功能）。
